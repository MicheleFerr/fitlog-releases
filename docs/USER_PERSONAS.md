# 👥 FitLog Pro - User Personas

**Ultimo aggiornamento**: 2026-02-08
**Versione**: 1.0

---

## 📋 Overview

FitLog Pro serve 5 personas principali, ciascuna con esigenze e comportamenti distinti. Ogni decisione di design/feature deve essere valutata attraverso il **Persona Impact Analysis**.

---

## 👤 Marco - Il Principiante Intimidito

### Profilo
| Aspetto | Dettaglio |
|---------|-----------|
| **Età** | 28 anni |
| **Esperienza fitness** | Neofita (0-6 mesi) |
| **Motivazione** | Vuole iniziare, ma si sente perso |
| **Device** | iPhone medio-gamma |
| **Sessioni/settimana** | 2-3 (obiettivo) |

### Core Needs
- 🎯 **Semplicità** → UI non intimidatoria
- 📚 **Guida** → Suggerimenti e spiegazioni
- 🏆 **Incoraggiamento** → Feedback positivo sui progressi
- 🔰 **Templates beginner-friendly** → Workout pre-costruiti semplici

### Pain Points
- ❌ Troppi dati/statistiche complesse
- ❌ Terminologia tecnica (RPE, 1RM, ecc.)
- ❌ UI affollata con troppe opzioni
- ❌ Sentirsi giudicato per le performance

### Comportamento App
- Usa principalmente **template pre-costruiti**
- Raramente crea workout custom
- Apprezza le **notifiche motivazionali**
- Consulta spesso la sezione **guida/tutorial**

### Quote
> "Vorrei solo sapere cosa fare, senza doverci pensare troppo"

---

## 👤 Chiara - La Mamma Multitasking

### Profilo
| Aspetto | Dettaglio |
|---------|-----------|
| **Età** | 35 anni |
| **Esperienza fitness** | Intermedia (ha fatto sport in passato) |
| **Motivazione** | Mantenersi in forma con tempo limitato |
| **Device** | iPhone recente |
| **Sessioni/settimana** | 3-4 (quando riesce) |

### Core Needs
- ⚡ **Velocità** → Tutto deve essere rapido
- 🚫 **Zero friction** → Nessun passaggio superfluo
- ⏱️ **Durata visibile** → Sa quanto tempo ha
- 📅 **Flessibilità** → Workout adattabili al tempo disponibile

### Pain Points
- ❌ Workflow lunghi (tap multipli)
- ❌ Caricamento lento
- ❌ Doversi ricordare cosa ha fatto
- ❌ Workout troppo lunghi senza alternative

### Comportamento App
- **Avvia workout in <10 secondi**
- Preferisce template salvati
- Usa la funzione **"Last performed"** per scegliere
- Apprezza workout da **20-30 min**

### Quote
> "Ho 25 minuti prima che i bambini tornino. Cosa posso fare?"

---

## 👤 Luca - Il Powerlifter Serio

### Profilo
| Aspetto | Dettaglio |
|---------|-----------|
| **Età** | 32 anni |
| **Esperienza fitness** | Avanzato (5+ anni) |
| **Motivazione** | Performance e progressione costante |
| **Device** | iPhone Pro |
| **Sessioni/settimana** | 5-6 |

### Core Needs
- 📊 **Dati dettagliati** → Vuole vedere tutto (kg, reps, RPE, volume)
- 📈 **Storico completo** → Analizzare progressi nel tempo
- 🎛️ **Controllo totale** → Personalizzazione massima
- 🔢 **Precisione** → Nessun arrotondamento, dati esatti

### Pain Points
- ❌ Mancanza di metriche avanzate
- ❌ Impossibilità di personalizzare
- ❌ UI troppo "gamificata" o infantile
- ❌ Dati imprecisi o aggregati

### Comportamento App
- Crea **workout custom complessi**
- Usa **supersets, dropsets, rest-pause**
- Consulta **grafici di progressione** settimanalmente
- Esporta dati per analisi esterne

### Quote
> "Voglio sapere esattamente quanti kg ho sollevato 6 settimane fa sullo squat"

## 👤 Sofia - L'Estetica-Driven

### Profilo
| Aspetto | Dettaglio |
|---------|-----------|
| **Età** | 26 anni |
| **Esperienza fitness** | Intermedia (2-3 anni) |
| **Motivazione** | Aspetto fisico e benessere |
| **Device** | iPhone ultimo modello |
| **Sessioni/settimana** | 4-5 |

### Core Needs
- 👀 **Progressi visibili** → Foto, misure, trasformazione
- 🎨 **Design premium** → L'app deve essere bella
- 🏅 **Gamification** → Badge, streak, achievements
- 📱 **Social sharing** → Condividere i successi

### Pain Points
- ❌ UI brutta o datata
- ❌ Mancanza di feedback visivo
- ❌ Nessun elemento motivazionale
- ❌ Impossibilità di tracciare oltre il peso

### Comportamento App
- Controlla **streak e badge** frequentemente
- Usa **foto progresso** (se disponibile)
- Condivide achievements sui social
- Apprezza **animazioni e micro-interazioni**

### Quote
> "L'app che uso dice molto di me. Deve essere bella oltre che funzionale"

---

## 👤 Roberto - Il Professionista Busy

### Profilo
| Aspetto | Dettaglio |
|---------|-----------|
| **Età** | 42 anni |
| **Esperienza fitness** | Intermedia (mantiene forma) |
| **Motivazione** | Salute e efficienza |
| **Device** | iPhone Pro Max (per lavoro) |
| **Sessioni/settimana** | 3-4 |

### Core Needs
- 🎯 **Efficienza massima** → Nessun tempo sprecato
- 📋 **Routine consolidate** → Non vuole inventare workout
- 🔔 **Reminder intelligenti** → Notifiche utili, non spam
- 💼 **Professionalità** → App seria, non giocattolo

### Pain Points
- ❌ Funzionalità inutili che rallentano
- ❌ Troppi step per fare cose semplici
- ❌ Notifiche eccessive
- ❌ UI che richiede attenzione costante

### Comportamento App
- Ha **3-4 template fissi** che alterna
- Avvia workout dalla **home in 2 tap**
- Usa **Apple Watch** per controllare timer
- Non esplora mai nuove funzionalità

### Quote
> "Ho 45 minuti tra due call. L'app deve aiutarmi a sfruttarli al massimo"

## 🔄 Persona Impact Analysis Framework

### Come Usarlo

Prima di ogni decisione significativa:

```
┌─────────────────────────────────────────────────────────────┐
│  1. Identifica impatto per OGNI persona:                   │
│     ++ = Molto positivo                                     │
│     +  = Positivo                                           │
│     0  = Neutro                                             │
│     -  = Negativo                                           │
│     -- = Molto negativo (BLOCKER)                           │
│                                                             │
│  2. BLOCCA se persona primaria ha "--"                     │
│  3. RIVEDI se 3+ personas hanno "-"                        │
│  4. Proponi mitigazioni per impatti negativi               │
└─────────────────────────────────────────────────────────────┘
```

### Template Analisi

```markdown

**Decisione**: ✅ Procedi / ⚠️ Rivedi / ❌ Blocca
**Mitigazioni**: ...
```

Per feature in conflitto, usa questa priorità:

| Scenario | Priorità |
|----------|----------|

| **Daily workout** | Chiara > Roberto > Luca |
| **Analytics/Stats** | Luca > Roberto > Sofia |
| **Design/Visual** | Sofia > Marco > Chiara |
| **Advanced features** | Luca > Roberto > Sofia |
